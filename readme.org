* r4.el
Browse, play and download [[https://radio4000.com][radio4000.com]] channels from Emacs.

- Browse and search channels and tracks (Radio4000 Supabase API).
- Play channels with =mpv=: a queue, shuffle, pause, seek, volume,
  and the current track in the mode line.
- Download tracks as high quality audio with =yt-dlp= into
  =~/Music/radio4000/<channel>/=, with an =<channel>.m3u= playlist.
  Downloaded tracks are played from disk instead of streamed.
- Local-first channels: create channels and add tracks without a
  radio4000.com account, or save a copy of any channel to browse it
  offline.

** Requirements
- Emacs 29.1 or newer.
- [[https://mpv.io][mpv]], to play tracks.
- [[https://github.com/yt-dlp/yt-dlp][yt-dlp]] (recent), and =ffmpeg=, to download and stream tracks.

YouTube changes often: keep yt-dlp up to date (=pipx install yt-dlp=
or =pipx upgrade yt-dlp=, distribution packages are often too old).
yt-dlp also needs a JavaScript runtime for YouTube, see [[https://github.com/yt-dlp/yt-dlp/wiki/EJS][yt-dlp/wiki/EJS]].
With =deno= installed it works out of the box; for =bun= or =node=,
add it to =~/.config/yt-dlp/config= (used by both r4 downloads and
mpv streaming):

#+begin_src conf
--js-runtimes bun
#+end_src

** Installation
#+begin_src emacs-lisp
(use-package r4
  :vc (:url "https://gitlab.com/ugrp/lisp/r4.el" :rev :newest)
  :bind ("C-c r" . r4))
#+end_src

Or =M-x package-vc-install RET https://gitlab.com/ugrp/lisp/r4.el=.

** Usage
=M-x r4= opens a menu with all the commands.

| Command                  | Description                                  |
|--------------------------+----------------------------------------------|
| =r4-channels=            | List channels, most recently active first    |
| =r4-search-channels=     | Full-text search of channels                 |
| =r4-open-channel=        | List the tracks of a channel (with completion) |
| =r4-search-tracks=       | Full-text search of all tracks               |
| =r4-play-channel=        | Play a channel                               |
| =r4-download-channel=    | Download all the tracks of a channel         |
| =r4-downloads=           | List downloads and their progress            |
| =r4-queue=               | Show the play queue                          |
| =r4-local-create-channel= | Create a local channel                      |
| =r4-local-add-track=     | Add a track by URL to a local channel        |
| =r4-local-open-channel=  | List the tracks of a local channel           |
| =r4-local-save-channel=  | Save a copy of a channel, to browse offline  |

In channel and track lists, =C-h m= shows all the keys. The main ones:

| Key   | Tracks list                        | Channels list        |
|-------+------------------------------------+----------------------|
| =RET= | Play from this track               | Open channel         |
| =P=   | Play all                           | Play channel         |
| =z=   | Shuffle play                       |                      |
| =SPC= | Pause/resume                       | Pause/resume         |
| =n= =p= | Next/previous track              | Next/previous track  |
| =m= =u= =U= =M= | Mark, unmark, unmark all, mark all |      |
| =d=   | Download marked tracks or at point |                      |
| =D=   | Download all                       | Download channel     |
| =a=   | Add to a local channel             |                      |
| =x=   | Remove from this local channel     |                      |
| =S=   | Save channel locally               |                      |
| =s=   | Search tracks                      | Search channels      |
| =o=   | Open on radio4000.com              | Open on radio4000.com |
| =g=   | Refresh                            | Refresh              |

The first column of a tracks list shows =▶= for the playing track,
=✓= for downloaded tracks and =↓= for queued downloads.

** Configuration
=M-x customize-group RET r4=. For example:

#+begin_src emacs-lisp
(setq r4-download-directory "~/Music/radio4000/" ; the default
      r4-download-audio-format "flac"            ; nil keeps the original audio, without re-encoding
      r4-download-max-processes 3
      r4-channels-min-tracks 10)                 ; hide small channels
#+end_src

** Local channels
A local channel is a file in the radio4000.com backup format
(version 2), stored with its downloads:

#+begin_example
~/Music/radio4000/my-radio/
├── my-radio.json   ; the channel and its tracks
├── my-radio.m3u    ; playlist of the downloaded tracks
└── Artist - Title [media-id].opus
#+end_example

It can be imported into radio4000.com, versioned with git, or synced
between machines like any other file.
