* r4-mode
An Emacs major mode to browse [[https://radio4000.com][radio4000.com]].

Inspiration from =list-buffers=, =magit=, =ibuffer=, =list-packages=, =tabulated-list-mode=, =docker=, =info=.

** Installation
*** Development
1. install the dependency package `emacs-request`, https://github.com/tkf/emacs-request
1. clone this repository
1. open the file =./r4.el= in an emacs buffer (=M-x find-file RET ./r4.el=)
1. =M-x evaluate-buffer=
