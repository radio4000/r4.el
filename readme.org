* r4-mode
An Emacs major mode to browse [[https://radio4000.com][radio4000.com]] (through [[https://api.radio4000.com][api.radio4000.com]]).

** Installation

> Only tested on linux (arch) for now (so mpv dependency might not work else-where).

*** Development
1. install =mpv= [[https://mpv.io/installation][mpv.io/installation]]; a free media player for the command line
1. install the dependency package =emacs-request=, [[https://github.com/tkf/emacs-request][github/tkf/emacs-request]]; used to make http network requests (to api.r4.com)
1. clone this repository
1. open the file =./r4.el= in an emacs buffer (=M-x find-file RET ./r4.el=)
1. =M-x evaluate-buffer=


Alternatively it is possible to use =M-x package-install-file r4.el=.
This way the package is available under `M-x list-packages`.

**** debug

If there is an error happening, you can use `M-x
toggle-debug-on-error`, to activate globally enterring in the debug
mode when the error happens again.
