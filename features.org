#+TITLE: r4.el features
#+OPTIONS: toc:2

What radio4000.com (the web app) and =r4= (the command line) do, and
how to do it in Emacs. The keys are the same in every r4 list where
they make sense, and =?= in a list shows all its keys.

* Principles
- One command per action, named =r4-<thing>-<action>=, callable with
  =M-x= from anywhere, and bound to the same key in every list.
- Lists are plain =tabulated-list-mode= buffers: =n= =p= move, =S=
  sorts, =g= refreshes, =m= =u= mark, =q= quits.
- The player keys work in every r4 list and in the =r4= menu.
- Downloads use the same folders and file names as =r4 download=, so
  the command line, Emacs and the radio4000.com import share them.

* Browse
| Feature                                  | Web / CLI                         | Emacs                          | Key       |
|------------------------------------------+-----------------------------------+--------------------------------+-----------|
| List channels                            | /explore/channels, =r4 channel list= | =r4-channels=               | menu =c=  |
| Search channels                          | /search/channels, =r4 search --channels= | =r4-search-channels=    | =s=       |
| Search tracks: =@slug #tag words=        | /search, =r4 search --tracks=     | =r4-search=                    | menu =s=  |
| Open a channel                           | /@slug, =r4 track list --channel= | =r4-open-channel=              | menu =o=  |
| Channel details, image                   | /@slug, =r4 channel view=         | =r4-describe-channel=          | =i=       |
| Tracks with a tag (one channel or all)   | /@slug/tags, /tags, =--tag=       | =r4-tracks-filter-tag=, =r4-search= | =#=  |
| Filter the shown tracks                  | queue and tracks filters          | =r4-tracks-filter=             | =/=       |
| Channel tags with counts                 | /@slug/tags, =r4 tags list=       | =r4-tracks-filter-tag=         | =#=       |
| Tracks mentioning a channel              | /@slug/mentions                   | =r4-mentions=                  | menu =@=  |
| Open the channel of a track              | link                              | =r4-tracks-open-channel=       | =@=       |
| Open on radio4000.com, copy links        | share                             | =r4-*-browse=, =r4-*-copy-*=   | =o= =O= =w= =W= |

* Not in Emacs
- Map, 3D universe, decks and video layouts: visual features of the web app.
- Broadcasting your own player: listening works, broadcasting needs a
  realtime connection.
- Soulseek downloads (=r4 download --source soulseek=).
- Track metadata from MusicBrainz and Discogs.
