#+TITLE: r4.el features
#+OPTIONS: toc:2

What radio4000.com (the web app) and =r4= (the command line) do, and
how to do it in Emacs.  Every command works with =M-x= from anywhere;
the keys are the ones of the r4 lists, where =?= shows them all.

* Principles
- One command per action, named after what it acts on: =r4-tracks-…=
  for the tracks of a list, =r4-channels-…= for channel lists,
  =r4-player-…= for the player.
- Names come from radio4000.com: the columns are the fields of its
  channels and tracks, such as "created at" and "track count", and the
  menus use the words of its interface.
- Lists are plain =tabulated-list-mode= buffers: =n= =p= move, =S=
  sorts by the column at point, =g= refreshes, =m= =u= mark, =q= quits.
- The same key does the same thing in every list, and the player keys
  and the main views (=h= home, =j= visit a channel, =E= explore, =B=
  broadcasts, =H= history) work in every r4 buffer, like in magit.
- Downloads use the same folders and file names as =r4 download=, so
  the command line, Emacs and the radio4000.com import share them.

* Not in Emacs
- The map, the 3D universe, decks and video layouts: visual features of
  the web app.  Channel descriptions link to a map of the channel.
- Soulseek downloads (=r4 download --source soulseek=).
- Track metadata from MusicBrainz and Discogs.
- Uploading channel images.
